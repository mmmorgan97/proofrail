# Security policy

Proofrail is experimental software. It can launch commands defined in a plan; command execution is not sandboxed. Do not run plans from untrusted sources, and inspect the exact plan before authorizing it. The plan hash is a change detector, not a signature or proof of human review.

Do not use Proofrail to authorize high-impact or irreversible actions.

To report a security issue, please open a private vulnerability report through GitHub's **Security → Report a vulnerability** feature if enabled for the repository. Until a public repository exists, do not include secrets, tokens, or private data in a report sent through public channels.
